Stock Analytics Dashboard

Compute and interpret key risk and return metrics for any publicly traded security using historical market data sourced via Yahoo Finance.

This tool calculates expected return, variance, and standard deviation from historical price data — the core statistical measures used in quantitative finance to evaluate individual securities before constructing or rebalancing a portfolio.

New to quantitative investing? Visit the Terminology page for clear definitions of every metric and concept used across this platform.

  • Expected return — annualised mean return derived from historical price series
  • Variance & standard deviation — measures of volatility and total risk
  • Risk/return comparison — evaluate securities side by side before investing
  • Investment optimisation — weight allocations for maximum risk-adjusted return
